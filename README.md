## Financial Chatbot Prototype

## Overview
This is a simple rule-based financial chatbot built using Python.
It answers predefined financial questions based on analyzed
10-K financial data of Microsoft, Apple, and Tesla.

## Predefined Queries
- What is the total revenue?
- How has net income changed over the last year?
- Which company has the highest revenue?
- Is operating cash flow increasing?
- Help

## How It Works
- User input is matched using if-else conditions
- Each question maps to a predefined response
- No machine learning or NLP is used

## Limitations
- Cannot answer questions outside predefined queries
- Financial values are static (hardcoded)
- No real-time data or natural language understanding

## Future Improvements
- Connect to live financial databases
- Add NLP for flexible queries
- Integrate with a web interface or AI models
